## 已验证的飞猪查询

使用锁定的官方 CLI 1.0.16 对 `SHA → CAN / 2026-10-15 / 直飞` 进行了网络查询，返回 10 条平台结果，包括虹桥与浦东的混合结果。项目适配器仅保留请求的实际机场，支持次日到达时间。没有创建订单或发送邮件。

实测返回 `ticketPrice`，但没有机场建设费、燃油附加费、含税总价保证等字段，因此只作为候选价格展示。官方体验提示说明结果受限，正式 Key 可增加可用服务。价格随时变化，测试结果不作为用户当前出行推荐。

FlyAI 原生查询通过官方 CLI 完成，不复制或手工维护其内部鉴权、签名、体验密钥。项目仅传入查询机场、日期、直飞/转机选项及用户配置的 Key。支持无 Key 体验，不表示持续服务免费或无限量。

## 完成其他来源接入需要什么

1. 在官方渠道取得允许票价搜索的账号权限（仅平台注册或普通乘客账号不足以证明已开通）。
2. 提供搜索 API 文档或其本地路径、测试环境地址、认证方式、脱敏响应示例，以及费用字段说明。
3. 凭据填写到本地配置，避免粘贴到聊天、日志或 Git。原生协议需完成代码适配，不能直接放入当前统一 JSON 接口字段。
4. 若已有服务商提供符合 README 的统一报价协议，可直接添加“统一协议接口”。

未替用户注册、签署协议、申请付费服务或发送合作邮件。平台准入与授权需要用户本人或企业完成。
